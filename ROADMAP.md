# Следующие улучшения BookWords

Предложения по текущему приложению, 10 ноября 2026. Это идеи, не реализованные функции.

1. **Упражнения по предложениям из книги.** Скрывать изучаемое слово в сохранённой цитате. После ответа показывать предложение целиком, перевод и произношение. Это следующий рекомендуемый шаг: приложение использует уже сохранённый контекст.
2. **Работа над ошибками.** Отдельная короткая сессия из слов, на которых пользователь ошибался, с историей сложностей по режимам: перевод, письмо, слух. Не считать слово освоенным только по выбору из вариантов.
3. **Значения и устойчивые сочетания.** Несколько значений с частью речи, типичными сочетаниями и примерами. При проверке принимать сохранённые подходящие переводы и показывать, какое значение употреблено в книге.
4. **Быстрый сбор слов при чтении.** Вставить абзац, выбрать слова, сохранить вместе с предложениями и номером страницы. Сначала показать предварительный список и дубликаты.
5. **Понятный прогресс.** Сколько слов перешли в устойчивое знание, сколько вернулись на повторение и какие книги дают больше новой лексики. Дневной план по времени: 5, 10, 15 минут.
6. **Надёжные иллюстрации.** Существующий внешний генератор ранее возвращал изображение лимита вместо сцены. Нужны управляемый провайдер, хранение готовых картинок и понятная замена при недоступности.

Синхронизация v28 уже закрывает перенос по коду, ошибки связи и явные конфликты. Следующий отдельный этап — слияние разных добавлений и история нескольких резервных копий вместо единственной последней.
